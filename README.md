# 🧭 NavHub - 个人网址导航

一个**纯前端、零后端、零费用**的个人网址导航站，Fork 到 GitHub 开启 Pages 即可使用，无需服务器、无需数据库、无需构建。

> 灵感来自 cf-navs（Cloudflare 导航模板），但本项目的目标是**部署最简单**：数据存浏览器本地 + 可一键导出备份；内置原站 16 个分类 91 条书签与资源大全 434 条（共 27 分类 525 条），UI 融合 daott.cn 与新标签页风格，支持动态视频背景、跑马灯公告，开箱即用。

## 🚀 三步部署到 GitHub Pages

### 第 1 步：创建自己的仓库

方式一（推荐）：**Fork 本仓库** → 到你账号下，Fork 后仓库名可改（如 `my-nav`）。

方式二：手动上传 —— 新建一个仓库（Public 即可），把本项目所有文件上传进去：
```
index.html
css/style.css
js/app.js
js/admin.js
data/default-data.json
```

### 第 2 步：开启 GitHub Pages

1. 进入你的仓库 → **Settings** → 左侧 **Pages**
2. **Branch** 选择 `main`（或你用的分支），目录选 `/ (root)` → **Save**
3. 等待 1~2 分钟构建完成

### 第 3 步：访问

- 打开 `https://<你的用户名>.github.io/<仓库名>/`
- 例：用户名 `zhangsan`、仓库 `my-nav` → `https://zhangsan.github.io/my-nav/`
- 如果绑定了自定义域名，也可在 Pages 设置里配置

✅ 完成！点右上角 **⚙️ 管理** 就能增删改导航，点 **💾 保存** 立即生效。

## 🛠️ 使用说明

### 日常使用
- 点分类按钮只看某一类；搜索框实时过滤全部资源
- 回车直接打开第一个匹配结果（新标签页）

### 管理导航
1. 点右上角 **⚙️ 管理**
2. 分类/分组/书签均可：改名、改图标、上下移动排序、删除
3. 修改后点 **💾 保存** 生效（数据保存在当前浏览器 localStorage）
4. 换电脑/换浏览器时，先 **⬇️ 导出备份**，再在另一台 **⬆️ 导入备份**

### 修改默认数据（可选）
- 直接编辑 `data/default-data.json` 再推送到 GitHub，新访客就会加载新数据
- 结构：`site`（站点信息）+ `categories`（分类数组，含 `name` / `icon` / `groups`）

```json
{
  "site": { "title": "我的导航", "subtitle": "收藏常用网站，一处直达", "theme": "auto" },
  "categories": [
    {
      "name": "常用",
      "icon": "🏠",
      "groups": [
        { "name": "默认", "bookmarks": [ { "title": "GitHub", "url": "https://github.com" } ] }
      ]
    }
  ]
}
```

## ⚠️ 注意事项

- **数据保存在浏览器本地**：在某个浏览器里修改的内容，不会自动同步到其他设备。跨设备请用「导出/导入备份」迁移。
- 清理浏览器缓存/换浏览器会"丢失"修改 —— 所以记得定期导出备份（或直接把成果写回 `data/default-data.json`）。
- 本项目为个人导航用途，无账号体系、无云端，天然适合低维护场景。

## 🧪 本地预览（可选）

无需任何依赖，直接用浏览器打开 `index.html` 即可（或起个本地静态服务）：

```bash
# 任选其一
python3 -m http.server 8080
# 或
npx serve .
# 然后浏览器访问 http://localhost:8080
```
